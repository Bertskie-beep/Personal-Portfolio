OSBERT VERDIDA — NARUTO-INSPIRED PERSONAL PORTFOLIO

FILES
- index.html: HTML5 page content and sections
- style.css: CSS3 layout, responsive styling, ninja/anime-inspired theme, and fire cursor
- README.txt: setup and customization notes

OPEN THE WEBSITE
1. Extract this ZIP file.
2. Open the folder in Visual Studio Code.
3. Open index.html in a browser, or use the Live Server extension.

CUSTOMIZE BEFORE PUBLISHING
- Replace your.email@example.com with your public contact email.
- Replace the GitHub and LinkedIn links with your actual profile URLs.
- Update project details and achievements to match your completed work.
- Your supplied profile photo is included as profile-photo.jpg and displayed in the About section. Keep it in the same folder as index.html.

TECHNOLOGY
HTML5 and CSS3 only — no JavaScript. The flame cursor uses a small inline SVG data URI in the CSS. Google Fonts are loaded online with local fallback fonts. The visual style is inspired by ninja anime and fiery chakra colors; it uses original CSS artwork rather than copied Naruto character images.
