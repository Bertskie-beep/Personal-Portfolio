File / Folder	Description
index.html	The homepage and main introduction to the portfolio.
about.html	A page containing my personal profile, background, and interests.
gallery.html	A page for displaying project screenshots, activities, and other portfolio images.
css/style.css	Contains the website's visual design, layout, colors, responsive styling, and flame-shaped cursor.
images/	Stores the profile photo and other images used by the website.
README.md	Provides information about the project, its structure, and setup instructions.


Technologies Used
- HTML5 — Structures the content and pages.
- CSS3 — Handles the design, layout, animations, responsive appearance, and custom fire cursor.
This project is designed using HTML5 and CSS3 only. It does not require JavaScript.
Design Features
- Naruto-inspired ninja theme and Will of Fire color palette.
- Dark background with orange and gold accents.
- Custom flame-shaped mouse cursor.
- Profile, skills, achievements, and project showcase sections.
- Responsive layout for desktop, tablet, and mobile screens.
- Separate pages for the homepage, about section, and image gallery.
Customization
- Replace images/profile-photo.jpg with your preferred profile photo. Keep the same filename or update the image path in the HTML.
- Add your own projects and achievements to the relevant pages.
- Update the contact details and social media links with your actual accounts.
- Edit css/style.css to customize the colors, typography, spacing, and visual effects.
